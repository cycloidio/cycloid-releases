# [v6.23.0] _2026-09-08_

*This release improves reliability across plugins, StackForms, notifications, and activity reporting.*

## 🐛 Fixes

* **Plugins:** Reinstall a plugin successfully after a failed installation, without timing out on a terminating deployment. [ENG-333](https://linear.app/cycloid/issue/ENG-333/plugin-manager-writes-to-a-terminating-deployment-so-re-installing)
* **StackForms:** Update components using `values_ref` credentials resolved from the component’s organization. [ENG-346](https://linear.app/cycloid/issue/ENG-346/values-ref-credential-resolved-against-the-stacks-org-instead-of-the)
* **Notifications:** Background polling failures no longer show misleading network-error popups. [ENGFE-488](https://linear.app/cycloid/issue/ENGFE-488/remove-error-accessing-network-popup-message)
* **Activity reports:** Daily email reports identify the member responsible for each action instead of showing “Unknown member.” [ENG-317](https://linear.app/cycloid/issue/ENG-317/email-daily-report-showing-unknown-member)
