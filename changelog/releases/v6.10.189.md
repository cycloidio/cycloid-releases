## API
### **FIXED**
- **Components**: GetComponentConfig no longer times out ("operation aborted") under concurrent load. Config-repo reads no longer take a distributed write-lock and read straight from the git object tree under a shared lock, so concurrent reads scale instead of serializing on per-clone worktree materialization.
### **ADDED**
- **Service Catalog**: Allow marking a stack as unique so it can be instantiated only once per organization, project and environment [PROD-794](https://linear.app/cycloid/issue/PROD-794)
### **FIXED**
- **StackForms**: Reinstated support for legacy v1/v2 StackForms and the bare (non-$-prefixed) condition syntax that was dropped in v6.10.169, which broke existing stacks whose conditions did not use the $variable syntax. Such stacks load and validate again without changes. [BE-1486](https://linear.app/cycloid/issue/BE-1486)
