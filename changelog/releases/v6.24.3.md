# [v6.24.3] _2026-11-04_

## ✨ New

* **Administration:** Root-organization admins can list all users—including users without an organization—and delete users through the admin API and CLI, with last-admin protections. [PROD-886](https://linear.app/cycloid/issue/PROD-886/close-the-last-admin-guard-holes-and-fix-hubspot-ordering-in-user) [PROD-887](https://linear.app/cycloid/issue/PROD-887/root-org-admin-api-and-cy-admin-users-delete-to-delete-any-user) [PROD-888](https://linear.app/cycloid/issue/PROD-888/root-org-admin-api-and-cy-admin-users-list-to-list-users-including) [PROD-889](https://linear.app/cycloid/issue/PROD-889/design-admin-user-provisioning-invite-or-create-a-user-in-an)
  * **What's new?**
    * `cy admin users list` supports pagination and email or organization filters.
    * `cy admin users delete --email` removes users and their organization memberships and API keys.
    * Deletion is blocked when it would leave an organization without an accepted administrator.
* **API access:** Parent-organization API keys retain their scoped permissions across descendant organizations, with events attributed to the originating key. [PROD-899](https://linear.app/cycloid/issue/PROD-899/scope-root-org-api-key-permissions-across-all-child-organizations) [PROD-906](https://linear.app/cycloid/issue/PROD-906/attribute-events-to-the-parent-org-api-key-when-it-acts-in-a-child)
  * **What's new?**
    * One key can apply resource-scoped permissions across child and grandchild organizations.
    * Scoped access remains limited to the resources covered by the key.
    * Events link back to the key in its owning organization.

## 🛠 Improvements

* **Plugins:** Automatic reconciliation and recovery of stale plugin-manager records during runtime migrations, including retries and cleanup of orphaned deployments. [ENG-486](https://linear.app/cycloid/issue/ENG-486/v624x-backport-plugin-manager-self-healing-arhs-253-arhs-264-blocking)
* **Authentication:** Organization updates preserve existing authentication methods and settings when those fields are not changed. [ENG-437](https://linear.app/cycloid/issue/ENG-437/fixauth-keep-authentication-methods-when-saving-organization-settings) [ENG-440](https://linear.app/cycloid/issue/ENG-440/fixorgs-keep-organization-settings-that-an-update-does-not-send)
* **Inventory:** Inventory resource, type, and label listings now respect the caller’s scoped inventory permissions. [PROD-905](https://linear.app/cycloid/issue/PROD-905/scope-the-inventory-resource-list-to-the-callers-scoped-inventory)
* **Security:** Scoped permission filters use safe parameter handling, preventing malformed resource names from altering list queries. [PROD-903](https://linear.app/cycloid/issue/PROD-903/bind-the-allowed-canonicals-of-scoped-rules-as-sql-parameters-in-list)

## 🐛 Fixes

* **Authentication:** Invite-only organizations now block uninvited email/password and SSO account creation, including sign-up attempts targeting child organizations. [ENG-436](https://linear.app/cycloid/issue/ENG-436/fixauth-harden-account-registration-on-invite-only-organizations) [ENG-451](https://linear.app/cycloid/issue/ENG-451/fixauth-apply-the-root-invite-only-setting-to-sso-account-creation-in)
* **Build logs:** Build-log streams now require authentication and pipeline read access; unauthorized requests receive 401 or 403 responses. [PROD-900](https://linear.app/cycloid/issue/PROD-900/enforce-authentication-and-pipeline-permissions-on-the-build-log)
* **Account deletion:** Last-administrator protections cover pending invitations and organizations with incomplete configuration, while HubSpot contact deletion occurs only after successful account deletion. [PROD-886](https://linear.app/cycloid/issue/PROD-886/close-the-last-admin-guard-holes-and-fix-hubspot-ordering-in-user)
* **Interface:** Menu and action icons reliably display after page load. [ENG-461](https://linear.app/cycloid/issue/ENG-461/some-cycloid-icons-are-not-displayed)
