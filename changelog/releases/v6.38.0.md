# [v6.38.0] _2026-11-17_

## ✨ New

* **Component configuration:** Lock a component’s StackForm configuration with an optional reason; locked values are read-only until explicitly unlocked. ENG- [PROD-907](https://linear.app/cycloid/issue/PROD-907/lock-a-components-stackform-configuration-to-prevent-changes)
  * **What's new?**
    * Lock and unlock controls for authorized users
    * Clear lock status and reason in the configuration view
    * Configuration and stack-version changes blocked while locked
    * Other component actions remain available

## 🛠 Improvements

* **Plugins:** Plugin iframe access now uses short-lived, widget-scoped tickets instead of session JWTs, preventing session tokens from reaching plugin pages and logs. [ENG-422](https://linear.app/cycloid/issue/ENG-422/plugin-iframe-urls-carry-the-viewers-session-jwt-which-reaches-plugin)
* **Invitations:** SSO sign-up from the root organization can accept a pending invitation to an eligible organization, including when the invitation link was not opened. Invitation tokens also persist safely across login and sign-up flows. [ENG-525](https://linear.app/cycloid/issue/ENG-525/user-access-issue)

## 🐛 Fixes

* **Credentials:** `cy_cred` configurations and credential creation now reject canonical names longer than 100 characters before creating an unusable credential. [ENG-528](https://linear.app/cycloid/issue/ENG-528/the-cy-cred-widget-can-create-a-credential-whose-canonical-exceeds-100)
