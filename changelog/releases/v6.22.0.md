# [v6.22.0] _2026-09-02_

*This release focuses on plugin reliability, component permissions, and several StackForms and workflow fixes.*

## ✨ New

* **Product:** Label selector support in the CLI and Terraform provider for selecting resources by label. [PROD-859](https://linear.app/cycloid/issue/PROD-859/add-label-selector-support-to-cli-and-terraform-provider)
* **Plugins:** Credential references in plugin configuration, including support for plugin install widgets and credential resolution at startup. [PROD-819](https://linear.app/cycloid/issue/PROD-819/credential-references-for-plugin-configuration)

## 🛠 Improvements

* **Product:** Component-scoped permissions for create, update, and delete operations, so component management no longer depends on `project:update`; project owners still retain component write access where applicable. [BE-473](https://linear.app/cycloid/issue/BE-473/add-separate-permissions-set-for-components) [ENG-324](https://linear.app/cycloid/issue/ENG-324/address-xescugcs-post-merge-review-findings-on-pr-6247)

## 🐛 Fixes

* **Plugins:** Plugin version publishing no longer fails intermittently during validation pod startup. [ENG-331](https://linear.app/cycloid/issue/ENG-331/plugin-version-publishing-fails-intermittently-port-forward-torn-down)
* **Plugins:** Autoscaled plugin deployments keep their live replica count instead of being reset to `MinReplicas` on every write. [ENG-330](https://linear.app/cycloid/issue/ENG-330/plugin-manager-resets-specreplicas-to-minreplicas-on-every-write)
* **Plugins:** Generated plugin pods keep a stable environment variable order, avoiding unnecessary recreate loops. [ENG-321](https://linear.app/cycloid/issue/ENG-321/plugin-manager-generates-pod-template-env-in-non-deterministic-order)
* **Plugins:** Generated CNI config restores the gateway and default route, so plugin containers can reach the API and DNS again. [ENG-337](https://linear.app/cycloid/issue/ENG-337/v6200-cri-plugin-runtime-generated-cni-config-omits-gatewayroutes)
* **Stacks:** New branches now appear after a single catalog refresh. [ENG-308](https://linear.app/cycloid/issue/ENG-308/selecting-new-branch-requires-2-refreshes)
* **Stacks:** A build now uses the composition that was just acknowledged by the write request. [ENG-313](https://linear.app/cycloid/issue/ENG-313/a-composition-write-acknowledged-with-204-is-not-reliably-visible-to-a)
* **Stacks:** Component configuration commits are flushed before update hooks run, preventing builds from using stale config. [ENG-328](https://linear.app/cycloid/issue/ENG-328/pipeline-builds-get-stuck-or-use-stale-config-due-to-async-git-commit)
* **Organizations:** API keys now return a usable token when created through Terraform. [ENG-312](https://linear.app/cycloid/issue/ENG-312/cycloid-organization-api-key-produces-a-token-that-fails-every-api)
* **Organizations:** Opening a cross-organization link no longer drops the session. [ENG-307](https://linear.app/cycloid/issue/ENG-307/some-links-are-not-working-as-expected)
* **Events & Notifications:** Project creation and settings pages no longer break when notification settings are missing. [ENG-326](https://linear.app/cycloid/issue/ENG-326/missing-notification-settings-breaks-project-creation-and-settings)
* **Stackforms:** Read-only templated defaults keep updating when their source field changes. [ENG-319](https://linear.app/cycloid/issue/ENG-319/interpolation-fails-to-update-reactively-on-read-only-widgets)
* **Stackforms:** Dropdown validation now runs when `values_ref` updates the value, and read-only dropdown errors are shown. [ENG-318](https://linear.app/cycloid/issue/ENG-318/dropdown-regexp-validation-not-triggered-with-values-ref-and-read-only)
