# [v6.24.0] _2026-09-15_

## ✨ New

* **StackForms credentials:** Controlled credential creation with fixed or prefixed names, locked types, preselected keys, and Vault-backed storage. [PROD-869](https://linear.app/cycloid/issue/PROD-869/add-controlled-inline-credential-creation-to-cy-cred) [PROD-865](https://linear.app/cycloid/issue/PROD-865/stackforms-allow-end-user-to-submit-a-sensitive-one-shot-secret-masked)
  * **What's new?**
    * Configure `cred_name`, `cred_name_prefix`, and `cred_key`.
    * Hide naming and selection fields when configured.
    * Interpolate and slugify configured names.
* **StackForms inputs:** Masked `simple_text` fields with password visibility controls. [PROD-870](https://linear.app/cycloid/issue/PROD-870/add-masked-sensitive-input-to-simple-text) [PROD-865](https://linear.app/cycloid/issue/PROD-865/stackforms-allow-end-user-to-submit-a-sensitive-one-shot-secret-masked)
  * **What's new?**
    * Enable masking with `sensitive: true`.
    * Toggle visibility while entering values.
* **Component pipelines:** Retrieve a component’s pipelines through a dedicated API endpoint, with job details populated in single-pipeline responses. [PROD-868](https://linear.app/cycloid/issue/PROD-868/the-api-seems-to-not-have-any-endpoint-to-retrieve-the-pipeline-of-a) [ENG-340](https://linear.app/cycloid/issue/ENG-340/when-fetching-the-pipeline-of-a-component-getpipeline-the-jobs-array)
  * **What's new?**
    * Query pipelines by organization, project, environment, and component.
    * Receive associated jobs and build information.
* **StackForms date/time constraints:** Backend support for all documented `date_time` configuration options. [ENG-348](https://linear.app/cycloid/issue/ENG-348/date-time-widget-scheduling-constraints-rejected-by-backend-form)
  * **What's new?**
    * Use future and past distance limits.
    * Restrict permitted times and dates.
    * Configure weekend and past-date behavior.

## 🛠 Improvements

* **StackForms validation:** Conditional fields, regexp failures, remote dropdown values, and read-only dropdowns now update validity and display errors correctly. [ENG-277](https://linear.app/cycloid/issue/ENG-277/save-button-stays-enabled-when-the-form-is-invalid-conditional) [ENG-318](https://linear.app/cycloid/issue/ENG-318/dropdown-regexp-validation-not-triggered-with-values-ref-and-read-only) [ENG-280](https://linear.app/cycloid/issue/ENG-280/conditional-values-format-renders-no-usable-input-in-the-frontend)
* **StackForms messages:** Validation messages support UTF-8 characters. [ENGFE-527](https://linear.app/cycloid/issue/ENGFE-527/support-utf-8-in-validationerror-messages)
* **Component search:** Search matches both component display names and canonical names. [ENG-373](https://linear.app/cycloid/issue/ENG-373/component-search-only-matches-the-canonical-not-the-display-name)
* **Component status:** Status reflects the most recently updated pipeline and build. [ENG-257](https://linear.app/cycloid/issue/ENG-257/the-component-is-marked-as-failed-while-its-latest-deployment-as)
* **Component configuration:** CLI reads and updates components using their pinned stack version by default, with clearer missing-file errors. [CLI-152](https://linear.app/cycloid/issue/CLI-152/cli-error-the-cycloid-yaml-file-was-not-found) [BE-560](https://linear.app/cycloid/issue/BE-560/error-message-not-helful-on-wrong-path-in-cycloidyml) [BE-1544](https://linear.app/cycloid/issue/BE-1544/cycloid-yaml-file-was-not-found)
* **CLI authentication:** Missing `CY_API_KEY` now produces a visible error and non-zero exit status; valid forms validation reports success. [CLI-155](https://linear.app/cycloid/issue/CLI-155/cy-login-exits-silently-with-code-0-when-cy-api-key-is-not-set)
* **Organization switching:** Switching organizations preserves menu visibility, authentication state, per-organization data, and session tokens, including when requests fail. [ENG-343](https://linear.app/cycloid/issue/ENG-343/menu-hidden-when-switching-organisation) [ENG-359](https://linear.app/cycloid/issue/ENG-359/sidebar-renders-differently-for-the-same-organization-depending-on-the) [ENG-360](https://linear.app/cycloid/issue/ENG-360/org-switch-leaves-inconsistent-auth-and-store-state-when-a-step-fails) [ENG-364](https://linear.app/cycloid/issue/ENG-364/stop-borrowing-the-session-token-to-list-a-parent-orgs-children)
* **Plugin widgets:** Component plugin widgets can be bound successfully, and plugin breadcrumbs no longer show the redundant “Plugins” level. [ENG-352](https://linear.app/cycloid/issue/ENG-352/component-plugin-widgets-can-never-be-bound-always-500-plugin-install) [ENG-345](https://linear.app/cycloid/issue/ENG-345/remove-plugins-from-the-breadcrumb)
* **Stack maintainers:** Maintainers of shared stacks can access branches and tags according to their owner-organization membership. [ENG-350](https://linear.app/cycloid/issue/ENG-350/maintainer-team-membership-check-fails-for-shared-stacks-branch)
* **API key details:** Newly created API keys immediately show the owner’s full name and email. [FE-1534](https://linear.app/cycloid/issue/FE-1534/api-key-owner-shows-incomplete-details-right-after-creation-correct)
* **Alert layout:** Alert content no longer conflicts with surrounding layout styles. [FE-1479](https://linear.app/cycloid/issue/FE-1479/cyalert-rename-inner-classcontent-to-remove-bem-collision-with-two)

## 🐛 Fixes

* **Pipeline data:** Unfinished builds no longer expose an invalid wrapped timestamp that can break API clients. [ENG-341](https://linear.app/cycloid/issue/ENG-341/buildend-time-reports-an-unfinished-build-as-18446744011573954816)
* **Configuration updates:** Empty naming-rule or cost tag-mapping updates are rejected instead of wiping existing configuration. [ENG-353](https://linear.app/cycloid/issue/ENG-353/emptynull-body-to-naming-rules-and-cost-tag-mapping-puts-silently)
