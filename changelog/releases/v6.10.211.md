# [v6.10.211] _2026-07-08_

## Console
### **ADDED**
- **Authentication**: Add "Adopt manually-invited members on OIDC login" toggle to the OIDC provider configuration panel [PROD-303](https://linear.app/cycloid/issue/PROD-303)
- **Environments**: Environment types can now define a label selector that restricts which stacks are offered when creating a component, with soft (filters the list, users can still show all stacks) or hard (non-bypassable) enforcement [FE-1511](https://linear.app/cycloid/issue/FE-1511)
### **FIXED**
- **Organizations**: fix 404 when switching to a child organization [ENG-220](https://linear.app/cycloid/issue/ENG-220)
- **Pipeline view**: render the component Overview pipeline widget by fetching the component's pipeline directly by name instead of scanning the project's pipeline list, which the API paginates to 100 — components whose pipeline was beyond the first 100 showed a blank Overview [OPS-1460](https://linear.app/cycloid/issue/OPS-1460)
- **Pipeline view**: fix the pipeline refresh diff wiping the pipeline — the diff preview now diffs against the git-rendered config (with the saved variables) in refresh/sync mode instead of an empty local config, and always sends the environment/component in the request [OPS-1460](https://linear.app/cycloid/issue/OPS-1460)
### **ADDED**
- **Project**: The projects list can now be filtered by stack and by component [FE-1374](https://linear.app/cycloid/issue/FE-1374)
- **Roles**: Hide individual sidebar submenus (e.g. Catalog repositories, Events, Credentials) from users whose roles don't grant the matching menu submenu permission, in both the sidebar and the section tab bars [FE-1515](https://linear.app/cycloid/issue/FE-1515)
### **FIXED**
- **Other**: shift-clicking a checkbox in a data table now range-selects between it and the last-clicked row, instead of only toggling the clicked row [FE-1516](https://linear.app/cycloid/issue/FE-1516)
- **Other**: Fix sidebar menu duplication when refreshing the page or switching organizations [ENG-217](https://linear.app/cycloid/issue/ENG-217)
## API
### **ADDED**
- **Authentication**: Add oidc_adopt_manual_members toggle to OIDC integration — when enabled, manually-invited members who log in via OIDC are automatically adopted (source flipped to 'oidc') so group mapping manages their membership going forward
- **Authentication**: Added menu permissions for the sidebar submenus [BE-1525](https://linear.app/cycloid/issue/BE-1525)
### **FIXED**
- **Authentication**: Fixed SSO invite-only onboarding that rejected invited users with "user must be explicitly invited to join this organization" and forced them to sign up twice. [ENG-219](https://linear.app/cycloid/issue/ENG-219)
- **Members**: Last login date now updates every hour instead of every 24 hours for more accurate display [ENG-208](https://linear.app/cycloid/issue/ENG-208)
### **ADDED**
- **Project**: The list projects endpoint can now be filtered by service catalog (stack) and by component canonical using LHS query filters (service_catalog_ref[eq]=..., component_canonical[eq]=...) [BE-1324](https://linear.app/cycloid/issue/BE-1324)
### **FIXED**
- **StackForms**: Fix conditional dropdowns showing "No data available" when a condition compares an unset field to an empty string [ENGBE-283](https://linear.app/cycloid/issue/ENGBE-283)
