# [v6.29.0] _2026-10-02_

## ✨ New

* **StackForms:** Password validation for inline-created `cy_cred` secrets using regular expressions, before the credential is created. [PROD-878](<https://linear.app/cycloid/issue/PROD-878/feature-request-validation-regex-sur-le-widget-cy-cred>)
  * **What's new?**
    * Validate the entered password rather than its credential reference.
    * Display individual validation messages.
    * Support complexity rules such as length, character classes, and special characters.

## 🛠 Improvements

* **Projects:** Fewer requests when loading project lists, including no unnecessary second-page request for empty lists. [ENG-390](<https://linear.app/cycloid/issue/ENG-390/projects-page-walks-every-page-of-projects-in-two-serial-waves>)
* **StackForms:** Read-only credentials no longer block updates due to newly added validation rules; “take me to the problem” reveals secret errors, and missing or invalid credential keys receive a specific message. [PROD-884](<https://linear.app/cycloid/issue/PROD-884/cy-cred-secret-validation-read-only-fields-take-me-to-the-problem>)

## 🐛 Fixes

* **CLI:** Clean pipeline-inference errors when no matching pipeline is found. [CLI-161](<https://linear.app/cycloid/issue/CLI-161/pipeline-inference-error-prints-percentwnil-when-the-component-has-no>)
* **Scheduler:** Concourse build-event streams close when builds finish or clients disconnect, preventing streams from accumulating indefinitely. [ENG-427](<https://linear.app/cycloid/issue/ENG-427/cycloid-api-v6220-keeps-concourse-build-event-streams-open>)
* **StackForms:** Required repeatable fields with blank rows now block form submission. [ENG-420](<https://linear.app/cycloid/issue/ENG-420/stackforms-required-repeatable-widget-with-empty-items-passes-the-form>)
* **API:** Malformed authentication updates now return a 422 validation error instead of causing a server error. [ENG-354](<https://linear.app/cycloid/issue/ENG-354/put-authentications-with-a-malformed-body-panics-500-instead-of-422>)
* **Sessions:** Logging out, stopping impersonation, or changing a password revokes the user’s active sessions. [ENG-415](<https://linear.app/cycloid/issue/ENG-415/pentest-improper-session-handling>)
