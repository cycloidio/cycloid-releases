# [v6.39.0] _2026-11-25_

## ✨ New

* **Plugins:** Enable widgets automatically when sharing a plugin with organizations, while allowing recipients to disable them. ENG-896
* **Git monitoring:** Scheduled repository health checks expose synchronization state, failures, last success, and failure counts as metrics. [PROD-910](https://linear.app/cycloid/issue/PROD-910/monitor-git-synchronization-status-between-cycloid-and-the)
  * **What's new?**
    * Checks repository access and configuration branches.
    * Supports optional write-readiness checks for configuration repositories.
    * Configurable interval and metrics collector settings.
* **Permissions:** Start API keys and roles from your permissions, a team, or an organization role; roles also enforce that users can grant only permissions they hold. [ENG-547](https://linear.app/cycloid/issue/ENG-547/api-keys-quick-way-to-set-permissions-copy-my-own-a-teams-or-a) [ENG-548](https://linear.app/cycloid/issue/ENG-548/roles-stop-members-granting-more-than-they-hold-and-share-the-start)

## 🛠 Improvements

* **Authentication:** One-hour access tokens refresh automatically, while sessions end at a configurable absolute lifetime. [ENG-421](https://linear.app/cycloid/issue/ENG-421/short-lived-session-tokens-with-proactive-refresh-and-an-absolute)
* **Credentials:** Credential canonicals can now be up to 250 characters, with validation across forms, APIs, the console, and Terraform. [ENG-528](https://linear.app/cycloid/issue/ENG-528/the-cy-cred-widget-can-create-a-credential-whose-canonical-exceeds-100)
* **Metrics:** Pipeline and Git collectors respect their configured interval even when multiple task-manager replicas are running. [PROD-911](https://linear.app/cycloid/issue/PROD-911/metrics-collectors-run-more-often-than-their-interval-with-several)

## 🐛 Fixes

* **Credentials:** Credentials with long canonicals can be deleted from Security → Credentials. [ENG-541](https://linear.app/cycloid/issue/ENG-541/credentials-whose-canonical-exceeds-100-characters-cannot-be-deleted)
* **StackForms:** Required multiselect dropdowns with one automatically selected option are saved as arrays. [ENG-549](https://linear.app/cycloid/issue/ENG-549/multiselect-required-dropdown-widgets-serialize-incorrectly-when-they)
* **Inventory:** Terraform state attributes and log highlights are sanitized, and special characters in searches no longer break the view. [ENG-539](https://linear.app/cycloid/issue/ENG-539/inventory-resource-details-render-terraform-state-attributes-as-raw)
* **Permissions:** API keys cannot receive permissions beyond those held by their creator. [ENG-540](https://linear.app/cycloid/issue/ENG-540/api-keys-restrict-granted-permissions-to-the-creators-own-permissions)
