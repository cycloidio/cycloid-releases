# [v6.31.0] _2026-10-15_

## ✨ New

**StackForms:** Configurable cost-estimation visibility and local-time date handling.

* **What's new?**
  * Hide the cost-estimation panel per stack.
  * Display date-time values in the user’s local time with the UTC equivalent.
  * Store date-time values in UTC while preserving date-only behavior.

[PROD-885](https://linear.app/cycloid/issue/PROD-885/stackforms-allow-disabling-the-estimate-the-cost-of-your-environment) [PROD-883](https://linear.app/cycloid/issue/PROD-883/stackformsdate-time-widget-show-values-in-the-users-local-time-and)

**Administration:** Root-organization user management and separate OIDC controls.

* **What's new?**
  * List and delete users through the admin API and CLI.
  * Protect the last administrator from removal.
  * Separate OIDC group mappings from reconciliation settings with independent permissions.
  * Record OIDC group-mapping and settings changes for auditing.

[PROD-892](https://linear.app/cycloid/issue/PROD-892/port-the-prod-629-admin-user-management-work-from-arhs-to-develop) [PROD-629](https://linear.app/cycloid/issue/PROD-629/expose-an-admin-api-for-user-access-management-and-provisioning) [PROD-890](https://linear.app/cycloid/issue/PROD-890/2-separate-tabs-for-oidc-group-mappings) [PROD-876](https://linear.app/cycloid/issue/PROD-876/audit-log-for-oidc-group-mapping-changes-ldap-group-to-cycloid-team)

## 🛠 Improvements

**Authentication:** Safer and faster access management for large organizations.

* Bulk OIDC group reconciliation reduces login fan-out.
* Stored member counts replace repeated recursive calculations.
* Email-based SSO account linking is limited to instance-trusted identity providers.

[ENG-452](https://linear.app/cycloid/issue/ENG-452/oidc-login-does-not-scale-on-large-installs-group-mapping-fan-out) [ENG-454](https://linear.app/cycloid/issue/ENG-454/store-the-distinct-licencesubscription-member-count-instead-of) [ENG-443](https://linear.app/cycloid/issue/ENG-443/fixauth-restrict-sso-email-based-account-linking-to-instance-trusted)

**Plugins:** Plugin widget states remain unchanged across upgrades, and duplicate or concurrent manager registrations no longer disrupt existing managers.

[ENG-411](https://linear.app/cycloid/issue/ENG-411/plugin-enableddisabled-state-is-reset-when-upgrading-version-or) [ENG-434](https://linear.app/cycloid/issue/ENG-434/registering-an-already-registered-plugin-manager-breaks-the-existing) [ENG-441](https://linear.app/cycloid/issue/ENG-441/concurrent-registrations-of-the-same-plugin-manager-url-can-still)

[ENG-429](https://linear.app/cycloid/issue/ENG-429/conditional-valuesoptions-widget-not-re-resolved-when-a-values-ref) [ENG-463](https://linear.app/cycloid/issue/ENG-463/values-ref-endpoints-resolve-any-org-credential-for-a-caller-chosen)
