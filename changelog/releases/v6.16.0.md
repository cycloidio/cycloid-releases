# [v6.16.0] _2026-08-06_

*StackForms, organization management, and plugin controls saw the biggest changes in this release.*

## ✨ New

* **Plugins**: Manage plugin sharing and widget views from the CLI and Terraform, including shared visibility, include/exclude org lists, and widget enablement or URL slug overrides for sub-orgs. [PROD-845](https://linear.app/cycloid/issue/PROD-845/cli-and-terraform-support-plugin-sharing-and-widget-view-management)
* **Plugins**: Shared plugin installs can now be used across org trees with multi-tenancy support and org-ownership checks. [ENG-263](https://linear.app/cycloid/issue/ENG-263/port-multi-registry-support-and-org-ownership-checks-from-standalone)
* **StackForms**: Dynamic form fields can now resolve `${...}` values inside `values_ref` URLs. [PROD-813](https://linear.app/cycloid/issue/PROD-813/implement-dynamic-variable-interpolation-in-form-fields)
* **StackForms**: `values_ref` calls can now use HTTP authentication and custom TLS settings, including a trusted CA certificate, server name, and insecure skip verify. [PROD-817](https://linear.app/cycloid/issue/PROD-817/add-authentication-support-for-values-ref-http-calls) [PROD-835](https://linear.app/cycloid/issue/PROD-835/add-tls-configuration-for-values-ref)
* **Project & Components**: Multiple Terraform state backends can now be scoped per component by label. [PROD-707](https://linear.app/cycloid/issue/PROD-707/multiple-terraform-state-backends)
* **Organizations**: The first root organization can now be created on a fresh install. [ENG-254](https://linear.app/cycloid/issue/ENG-254/unable-to-create-root-org-on-fresh-install)
* **Organizations**: Parent organization information now appears in the all-organizations view and on organization settings pages. [PROD-844](https://linear.app/cycloid/issue/PROD-844/display-parent-org-in-all-org-view)
* **Project & Components**: Organization member roles now have the read access needed to list cloud accounts. [ENG-260](https://linear.app/cycloid/issue/ENG-260/organization-member-role-missing-read-permissions-403)

## 🛠 Improvements

* **StackForms**: Prefilled widget values are validated as soon as the form loads, so invalid defaults show errors immediately. [ENG-253](https://linear.app/cycloid/issue/ENG-253/widget-validation-triggers-only-after-user-interaction)
* **StackForms**: Widgets now update when a switch value changes, and chained `values_ref` fields resolve in dependency order. [ENG-256](https://linear.app/cycloid/issue/ENG-256/values-ref-not-updating-when-switch-widget-changes) [PROD-837](https://linear.app/cycloid/issue/PROD-837/chained-values-ref-dependencies-show-stale-values)
* **StackForms**: Dynamic search fields ignore the special `__search__` placeholder when inferring dependencies. [ENG-267](https://linear.app/cycloid/issue/ENG-267/regression-on-dynamic-search)
* **Project & Components**: Component status now follows the most recent pipeline run instead of an older failed one. [ENG-257](https://linear.app/cycloid/issue/ENG-257/the-component-is-marked-as-failed-while-its-latest-deployment-as)
* **Project & Components**: Environment headers in card view are left-aligned again. [ENGFE-524](https://linear.app/cycloid/issue/ENGFE-524/project-overview-environment-header-content-is-centered-instead-of)

## 🐛 Fixes

* **StackForms**: Unfilled optional dynamic-search fields no longer show a spurious diff on update. [ENG-259](https://linear.app/cycloid/issue/ENG-259/unfilled-dynamic-search-widgets-show-spurious-diff-on-update)
* **StackForms**: Conditional groups no longer make unchanged values look new in the diff view. [ENG-264](https://linear.app/cycloid/issue/ENG-264/regression-on-stackform-diff)
* **StackForms**: Circular dependency detection no longer flags valid diamond-shaped dependencies. [ENG-275](https://linear.app/cycloid/issue/ENG-275/forms-circular-dependency-detection-false-positive-on-diamond)
* **StackForms**: Widgets hidden by their own condition are no longer written to the variables file. [ENG-252](https://linear.app/cycloid/issue/ENG-252/widget-level-conditions-write-values-to-variables-file)
* **StackForms**: Complex forms no longer fail to load or show every parameter as new in the diff view. [ENG-264](https://linear.app/cycloid/issue/ENG-264/regression-on-stackform-diff)
* **StackForms**: Pasting an SSH key into a hidden secret field keeps the line breaks intact. [ENGFE-523](https://linear.app/cycloid/issue/ENGFE-523/pasting-an-ssh-key-in-a-secret-ssh-field-merge-the-last-line-with-the)
* **StackForms**: `values_ref` dropdowns inside repeatable widgets now work correctly. [ENG-262](https://linear.app/cycloid/issue/ENG-262/dynamic-search-dropdown-fails-inside-repeatable-widget)
* **StackForms**: Interpolation and search behavior is protected by broader test coverage. [ENG-271](https://linear.app/cycloid/issue/ENG-271/improve-test-on-frontend-and-backend-for-interpolation)
