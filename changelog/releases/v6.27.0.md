# [v6.27.0] _2026-09-21_

*This release strengthens plugin reliability and resolves StackForms and component update regressions.*

## 🛠 Improvements

* **Plugins:** Deployment operations for the same plugin are serialized across processes, with lease loss stopping the operation rather than allowing it to continue without coordination. [ENG-400](https://linear.app/cycloid/issue/ENG-400/serialize-plugin-deployment-operations-across-processes-with-a-redis)
* **Plugin routing:** Cross-organization routing risks are reduced through additional runtime safeguards and stable Kubernetes service-name routing. [ENG-309](https://linear.app/cycloid/issue/ENG-309/close-residual-cross-org-plugin-routing-window-cri-mitigations-k8s-dns)

## 🐛 Fixes

* **Components:** Components pinned to tags can recover when the tag is updated to a new, previously unreachable commit. [ENG-302](https://linear.app/cycloid/issue/ENG-302/cycloid-component-tf-resource-fails-if-a-tag-commit-is-updated)
* **StackForms:** Hidden widgets using `values_ref` now load and propagate values correctly when dependent fields receive default values. [ENG-404](https://linear.app/cycloid/issue/ENG-404/hidden-widget-with-remote-values-and-nested-values-does-not-update)
