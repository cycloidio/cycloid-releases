# [v6.20.0] _2026-08-27_

*This release focused on StackForms and permission-model improvements, plus several fixes for configuration and plugin workflows.*

## ✨ New

* **StackForms:** Hide any widget with `hidden: true` while keeping its value, validation behavior, and `values_ref` support; `widget: hidden` remains supported as a deprecated alias. [PROD-857](https://linear.app/cycloid/issue/PROD-857/introduce-hidden-attribute-for-widgets)
* **Authentication:** Configure additional OIDC scopes and nested group-claim keys for identity providers that return groups inside nested claims. [PROD-854](https://linear.app/cycloid/issue/PROD-854/allow-configuring-additional-oidc-scopes-and-nested-claims)
* **Plugins:** Set a configurable readiness timeout for plugin pods during deployment. [PROD-850](https://linear.app/cycloid/issue/PROD-850/configurable-plugin-pod-readiness-timeout)

## 🛠 Improvements

* **Backend:** Component-specific permissions now control component create, update, delete, and stackform actions instead of relying on broader project अपडेट rights; project owners also retain component write access. [BE-473](https://linear.app/cycloid/issue/BE-473/add-separate-permissions-set-for-components) [ENG-325](https://linear.app/cycloid/issue/ENG-325/fix-project-creator-failures-found-in-component-permissions-staging)
* **StackForms:** `value_ref` URLs can now be made dynamic from the Cycloid instance context, so the same form can work across different environments. [PROD-647](https://linear.app/cycloid/issue/PROD-647/make-value-ref-url-dynamic-based-on-cycloid-instance)
* **Terraform state:** Deleting an external backend can now also remove its Terraform state with an optional delete setting. [PROD-849](https://linear.app/cycloid/issue/PROD-849/delete-the-tfstate-when-the-external-backend-is-deleted)
* **Backend:** Asynq handlers now use the standard application logger. [BE-877](https://linear.app/cycloid/issue/BE-877/provide-logger-for-asynq-handler)

## 🐛 Fixes

* **StackForms:** Forms stay usable when a stored dropdown value no longer matches any available option. [ENG-306](https://linear.app/cycloid/issue/ENG-306/form-fails-to-load-when-a-stored-dropdown-value-doesnt-match-any)
* **StackForms:** Dynamic defaults now apply on the first render in the preview. [ENG-300](https://linear.app/cycloid/issue/ENG-300/stackforms-preview-does-not-apply-dynamic-defaults-on-first-render)
* **StackForms:** Pending form changes are flushed before submit, preventing stale values from bypassing visibility and required-field checks. [ENG-295](https://linear.app/cycloid/issue/ENG-295/required-validation-ignores-condition-visibility)
* **StackForms:** Validations, conditions, and interpolated `values_ref` calls now work inside repeatable widgets. [ENG-303](https://linear.app/cycloid/issue/ENG-303/validations-conditions-and-values-ref-with-interpolation-broken-inside)
* **StackForms:** Nested `null` values in map fields are now preserved as HCL `null` instead of being silently dropped. [ENG-304](https://linear.app/cycloid/issue/ENG-304/stackforms-silently-discards-null-keys-nested-inside-a-structured-map)
* **StackForms:** Hidden widgets now support `values_ref`, including chained lookups that keep intermediate values hidden. [PROD-856](https://linear.app/cycloid/issue/PROD-856/support-values-ref-on-hidden-widget)
* **StackForms:** Hidden fields inside repeatable widgets and hidden-only groups are now handled correctly. [PROD-857](https://linear.app/cycloid/issue/PROD-857/introduce-hidden-attribute-for-widgets)
* **Components:** Branch-based versions now continue to follow the branch tip after commits are removed from the branch, instead of staying pinned to an old commit. [ENG-305](https://linear.app/cycloid/issue/ENG-305/removing-commits-from-a-branch-is-not-reflected-in-cycloid)
* **Components:** Saved configuration now stays intact when a referenced branch has been deleted and a new version is selected. [ENG-314](https://linear.app/cycloid/issue/ENG-314/when-a-branch-referenced-by-a-component-is-deleted-the-config-of-the)
* **Plugin routing:** Plugin records no longer route users into another organisation’s plugin when container addresses are reused. [ENG-296](https://linear.app/cycloid/issue/ENG-296/plugin-records-share-container-addresses-routing-users-into-another)
