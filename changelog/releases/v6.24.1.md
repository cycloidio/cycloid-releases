# [v6.24.1] _2026-09-29_

## 🛠 Improvements

* **Component migration:** Move components between environments without destroying and recreating them, while preserving Terraform state, re-rendering configuration, renaming pipelines, and updating pipeline settings for the destination. [PROD-855](https://linear.app/cycloid/issue/PROD-855/move-a-component-to-another-environment-tfpro) [ENG-378](https://linear.app/cycloid/issue/ENG-378/external-backend-repoint-and-tfstate-re-key-primitives-no-call-site) [ENG-381](https://linear.app/cycloid/issue/ENG-381/migrating-a-component-leaves-the-concourse-pipeline-under-the-old-name) [ENG-382](https://linear.app/cycloid/issue/ENG-382/migrating-a-component-leaves-its-external-backends-and-tfstate-at-the) [ENG-383](https://linear.app/cycloid/issue/ENG-383/re-render-component-config-files-on-migrate-instead-of-copying-them)
* **Local development:** SeaweedFS replaces MinIO as the S3-compatible storage service used by local development and end-to-end testing. [ENG-413](https://linear.app/cycloid/issue/ENG-413/replace-minio-with-seaweedfs-in-local-devtest-stack)

## 🐛 Fixes

* **Component migration:** Missing destinations now return clear 404 errors, and credential failures identify the affected backend and whether the source or destination was refused. [ENG-380](https://linear.app/cycloid/issue/ENG-380/migrating-a-component-to-a-missing-destination-returns-500-instead-of) [ENG-401](https://linear.app/cycloid/issue/ENG-401/verifystatecopy-loses-its-sourcedestination-context-so-a-credential)
* **Terraform state:** Conflicting state keys are rejected to prevent components from overwriting one another’s state. [ENG-399](https://linear.app/cycloid/issue/ENG-399/the-tfstate-object-key-is-an-unescaped-canonical-concatenation-so-two)
* **Component deletion:** Delete hooks use the stored pipeline name, so deleting a component after migration succeeds. [ENG-379](https://linear.app/cycloid/issue/ENG-379/component-delete-recomputes-the-pipeline-name-instead-of-using-the)
* **Environment management:** Environments and project links can no longer be removed when they still contain backends belonging to migrated components. [ENG-384](https://linear.app/cycloid/issue/ENG-384/deleting-an-environment-cascades-away-a-migrated-components-backend)
* **Pipeline configuration:** Migrated pipelines no longer reference the old environment. [ENG-394](https://linear.app/cycloid/issue/ENG-394/migrate-renames-the-concourse-pipeline-but-leaves-its-configuration)
