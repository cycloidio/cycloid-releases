# [v6.26.0] _2026-09-17_

## ✨ New

* **Stack versioning:** Organization admins can hide “out of sync” indicators from component and project lists while retaining other version statuses. [PROD-873](https://linear.app/cycloid/issue/PROD-873/hide-out-of-sync-stack-version-status-from-component-and-project-lists)
  * **What's new?**
    * Organization-level `hide_stack_version_out_of_sync` setting.
    * Applies only to component lists and project cards.
    * “Updates available” and deprecated-version indicators remain visible.

## 🛠 Improvements

* **Component migration:** Moving a component now renames its pipeline, updates pipeline configuration, repoints its external backends and Terraform state, and re-renders configuration files for the destination. [ENG-381](https://linear.app/cycloid/issue/ENG-381/migrating-a-component-leaves-the-concourse-pipeline-under-the-old-name) [ENG-382](https://linear.app/cycloid/issue/ENG-382/migrating-a-component-leaves-its-external-backends-and-tfstate-at-the) [ENG-383](https://linear.app/cycloid/issue/ENG-383/re-render-component-config-files-on-migrate-instead-of-copying-them) [ENG-394](https://linear.app/cycloid/issue/ENG-394/migrate-renames-the-concourse-pipeline-but-leaves-its-configuration)
* **Organization switching:** Faster organization switches with navigation that no longer updates when the switch fails. [ENG-361](https://linear.app/cycloid/issue/ENG-361/org-switch-is-a-4-deep-serial-request-waterfall-24s) [ENG-403](https://linear.app/cycloid/issue/ENG-403/org-switch-nav-fetch-harden-the-parallel-fetch-against-a-failed-switch)
* **Plugins:** Version upgrades update deployments in place, preserving the plugin’s Service, stored data, and identity during the upgrade. [ENG-365](https://linear.app/cycloid/issue/ENG-365/plugin-version-upgrade-destroys-the-deployments-service-and-stored)
* **StackForms:** Mapped dropdown dependencies consistently resolve to their API values, including when omitted from `depends_on`. [ENG-395](https://linear.app/cycloid/issue/ENG-395/stackforms-mapped-values-ref-dependencies-resolve-to-labels-when)

## 🐛 Fixes

* **Plugins:** Failed teardown keeps the plugin record instead of leaving the database and cluster resources out of sync. [ENG-336](https://linear.app/cycloid/issue/ENG-336/plugin-teardown-has-no-atomicity-in-either-direction-a-db-row-and-its)
* **Terraform state:** Component creation and migration now reject ambiguous state-object keys that are already used by another component. [ENG-399](https://linear.app/cycloid/issue/ENG-399/the-tfstate-object-key-is-an-unescaped-canonical-concatenation-so-two)
* **Component migration:** Missing destination projects or environments return a clear 404, and self-migrations are rejected. [ENG-380](https://linear.app/cycloid/issue/ENG-380/migrating-a-component-to-a-missing-destination-returns-500-instead-of)
* **Component deletion:** Delete hooks use the stored pipeline name, so deleting a migrated component no longer targets a nonexistent pipeline. [ENG-379](https://linear.app/cycloid/issue/ENG-379/component-delete-recomputes-the-pipeline-name-instead-of-using-the)
* **StackForms:** Dynamic search now works inside repeatable rows. [ENG-279](https://linear.app/cycloid/issue/ENG-279/dynamic-search-inside-a-repeatable-row-performs-no-search-fetch-fe)
* **StackForms:** Special characters in values interpolated into `values_ref` URLs are encoded correctly. [ENG-278](https://linear.app/cycloid/issue/ENG-278/interpolated-values-in-values-ref-urls-are-not-url-encoded-regression)
* **Forms:** Mapped `{label, value}` entries are accepted for string fields during validation and saving. [ENG-276](https://linear.app/cycloid/issue/ENG-276/mapped-label-value-values-rejected-by-forms-validation-and-by-the-save)
* **Environment management:** Environments cannot be deleted or unlinked when they still contain a migrated component’s backend or state. [ENG-384](https://linear.app/cycloid/issue/ENG-384/deleting-an-environment-cascades-away-a-migrated-components-backend)
* **CLI:** Team-member listing correctly accepts the team parameter. [CLI-156](https://linear.app/cycloid/issue/CLI-156/cli-api-fails-on-team-members)
