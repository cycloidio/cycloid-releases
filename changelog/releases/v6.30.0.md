# [v6.30.0] _2026-10-08_

*Security and reliability updates strengthen authentication, authorization, and service health across the platform.*

## 🛠 Improvements

* **StackForms:** Date-time fields now display values in the user’s local time with the UTC equivalent, store timed values in UTC, preserve date-only values, and apply time constraints in UTC. ENG-883
* **Vault:** Health checks succeed when Vault namespaces are configured by checking the root namespace. [ENG-327](https://linear.app/cycloid/issue/ENG-327/vault-health-check-fails-with-404-with-namespaces)

## 🐛 Fixes

* **Authentication:** Organization settings updates preserve configured authentication methods, and invite-only organizations now reject account creation without a valid invitation. [ENG-437](https://linear.app/cycloid/issue/ENG-437/fixauth-keep-authentication-methods-when-saving-organization-settings) [ENG-436](https://linear.app/cycloid/issue/ENG-436/fixauth-harden-account-registration-on-invite-only-organizations)
* **Authorization:** Organization messages now require appropriate authorization for reading and updating. [ENG-357](https://linear.app/cycloid/issue/ENG-357/organization-messages-routes-have-no-authorization-check-rbac-gap)
* **Organization roles:** Default member permissions now include the missing plugin read/list access, with existing member roles backfilled while sensitive organization, inventory, and child-organization permissions remain restricted. [ENG-339](https://linear.app/cycloid/issue/ENG-339/organization-member-role-missing-read-list-policies)
