# [v6.24.8] _2026-11-23_

## ✨ New

* **Git monitoring:** Health checks and metrics for configuration and stack repositories, including synchronization state, last successful check, failure counts, and error categories. [PROD-910](https://linear.app/cycloid/issue/PROD-910/monitor-git-synchronization-status-between-cycloid-and-the)
  * **What's new?**
    * Periodic repository health checks, configurable or disableable.
    * Optional write-access validation for configuration repositories.
    * Prometheus gauges exposed through the existing metrics endpoint.

## 🛠 Improvements

* **Metrics:** Pipeline and Git collectors now respect their configured interval when multiple task-manager replicas are running. [PROD-911](https://linear.app/cycloid/issue/PROD-911/metrics-collectors-run-more-often-than-their-interval-with-several)

## 🐛 Fixes

* **Authentication:** SSO sign-up now accepts pending invitations to child organizations when the user signs in through the root platform, provided the email is trusted. Invitation tokens also persist safely between login and sign-up flows. [ENG-525](https://linear.app/cycloid/issue/ENG-525/user-access-issue)
