# [v6.28.0] _2026-09-30_

## ✨ New

* **User impersonation:** Authorized support users can sign in as another user with traceable sessions and a 30-minute TTL. [PROD-674](https://linear.app/cycloid/issue/PROD-674/user-impersonation-godmod-for-support-with-full-traceability) [ENG-407](https://linear.app/cycloid/issue/ENG-407/impersonated-session-impersonator-claim-ttl-refresh-startstop) [ENG-406](https://linear.app/cycloid/issue/ENG-406/impersonation-allowlist-as-a-root-organization-setting) [ENG-408](https://linear.app/cycloid/issue/ENG-408/frontend-impersonation-login-page-banner-stop-and-restore-original)
  * **What's new?**
    * Dedicated impersonation login flow.
    * Banner showing the target and impersonator.
    * Stop action restores the original session.
    * Activity logs identify the impersonator.
* **Plugins:** Query variables now include the logged-in user’s email for filtering and personalization. [PROD-881](https://linear.app/cycloid/issue/PROD-881/add-user-email-as-plugin-query-speciable-variable)
  * **What's new?**
    * Use the current user’s email in plugin queries.
    * Available alongside existing always-available variables.
* **Organization settings:** Administrators can disable member invitation emails while leaving other transactional emails enabled. [PROD-872](https://linear.app/cycloid/issue/PROD-872/organization-setting-to-disable-member-invitation-emails)
  * **What's new?**
    * Organization-level control for invitation emails.
    * Applies to existing and new users.
    * Member creation continues without sending an invitation.

## 🛠 Improvements

* **Organizations:** Parent organizations are now shown in the selected-organization header and quick switcher, making similarly named sub-organizations easier to distinguish. [PROD-877](https://linear.app/cycloid/issue/PROD-877/show-parent-org-dg-beyond-the-see-all-org-view-selected-org-header)
* **StackForms:** Repeatable fields now correctly support remote values, type-ahead searches, and mapped dropdown values. [ENG-405](https://linear.app/cycloid/issue/ENG-405/repeatable-widget-stackforms-issue-with-value-ref)
* **StackForms:** Values referenced by free-typed fields wait for typing to pause before fetching updates. [ENG-316](https://linear.app/cycloid/issue/ENG-316/debounce-top-level-values-ref-fetches-fire-per-keystroke-on-simple)
* **Component migration:** Credential errors now identify the external backend and whether the source or destination failed. [ENG-401](https://linear.app/cycloid/issue/ENG-401/verifystatecopy-loses-its-sourcedestination-context-so-a-credential)
* **Credentials:** Invalid flat custom-credential payloads return a validation error instead of an internal server error. [ENG-355](https://linear.app/cycloid/issue/ENG-355/put-credentials-with-a-flat-raw-payload-returns-a-vault-500-instead-of)

## 🐛 Fixes

* **Impersonation:** Unverified email addresses can no longer be used to start an impersonated session or become a primary email. [ENG-418](https://linear.app/cycloid/issue/ENG-418/impersonation-allowlist-check-accepts-an-unverified-email)
* **Plugins:** Concurrent deployment updates no longer incorrectly mark a healthy plugin as failed. [ENG-335](https://linear.app/cycloid/issue/ENG-335/no-conflict-retry-around-the-plugin-deployment-read-then-write-so-an)
* **StackForms:** Forms no longer crash when groups share the same name. [ENG-412](https://linear.app/cycloid/issue/ENG-412/stackforms-form-crashes-in-hasvaluemapping-when-a-stack-has-duplicate)
* **StackForms:** Dependent interpolated defaults are re-resolved after upstream values change. [ENG-281](https://linear.app/cycloid/issue/ENG-281/interpolated-defaults-not-re-resolved-on-the-update-route-fe-keeps)
* **StackForms:** Date/time values are preserved when formats use `YYYY` or `DD` tokens. [FE-1531](https://linear.app/cycloid/issue/FE-1531/date-time-stackforms-widget-silently-discards-the-selected-value-when)
* **External backends:** Requests from another organization now return an authorization or validation error instead of a server error. [ENG-358](https://linear.app/cycloid/issue/ENG-358/external-backend-ops-return-500-to-a-foreign-org-token-should-be)
