# [v6.33.0] _2026-11-02_

## ✨ New

* **StackForms:** Stored forms can resolve credential-backed values through the stack’s configured references while preventing callers from redirecting requests to arbitrary hosts. [ENG-484](https://linear.app/cycloid/issue/ENG-484/values-ref-proxy-resolve-values-ref-config-from-the-stored-stack)
  * **What's new?**
    * Credentials remain usable without exposing their values.
    * Stored URLs, authentication, and headers cannot be replaced by request data.
    * Host substitutions are limited to declared static widget values.
* **Authentication:** Configurable JWT session duration, with session TTL enforced during token refresh. [BE-1424](https://linear.app/cycloid/issue/BE-1424/implement-configurable-jwt-session-duration-for-user-authentication)
* **Email:** SMTP can be intentionally disabled by leaving it unconfigured, without recurring errors or health-check failures. [PROD-897](https://linear.app/cycloid/issue/PROD-897/allow-running-cycloid-without-emailsmtp-configured-cleanly)
* **Access control:** Root-organization API keys can retain scoped permissions across descendant organizations, including future descendants. [PROD-899](https://linear.app/cycloid/issue/PROD-899/scope-root-org-api-key-permissions-across-all-child-organizations)
* **Infrastructure:** Redis Sentinel connection strings are supported by the distributed locker, allowing startup with highly available Redis deployments. [PROD-901](https://linear.app/cycloid/issue/PROD-901/the-backend-crashes-on-startup-when-connecting-to-a-redis-sentinel)

## 🛠 Improvements

* **StackForms:** Inline conditional fields now update through chained dependencies and continue updating when marked read-only. [ENG-520](https://linear.app/cycloid/issue/ENG-520/stackforms-a-read-only-field-with-inline-conditional-values-does-not) [ENG-519](https://linear.app/cycloid/issue/ENG-519/stackforms-inline-conditional-valuesoptions-do-not-propagate-through)
* **Authentication:** One-time email links are single-use, rate-limited, and expire; invitations and email-verification links expire after seven days. [ENG-423](https://linear.app/cycloid/issue/ENG-423/one-time-email-links-reuse-after-a-password-change-same-second-reuse)
* **Organization settings:** Concurrent settings updates preserve changes made by other administrators. [ENG-446](https://linear.app/cycloid/issue/ENG-446/fixorgs-apply-omitted-organization-settings-under-the-row-lock) [ENG-449](https://linear.app/cycloid/issue/ENG-449/fixconsole-send-only-the-edited-fields-when-saving-organization) [ENG-448](https://linear.app/cycloid/issue/ENG-448/fixorgs-create-organization-settings-rows-at-organization-creation)
* **Organizations:** Self-hosted organization-creation restrictions and root invite-only settings now apply consistently, including SSO sign-up. [ENG-439](https://linear.app/cycloid/issue/ENG-439/fixorgs-tighten-organization-creation-rules-on-self-hosted-instances) [ENG-451](https://linear.app/cycloid/issue/ENG-451/fixauth-apply-the-root-invite-only-setting-to-sso-account-creation-in)
* **Authentication:** SSO sign-up identity data must come from a server-verified identity, and linking no longer trusts unverified local accounts. [ENG-442](https://linear.app/cycloid/issue/ENG-442/fixauth-harden-sso-account-linking-against-unverified-local-accounts) [ENG-444](https://linear.app/cycloid/issue/ENG-444/fixauth-bind-sso-sign-up-to-a-server-verified-identity)
* **Security events:** Actions performed by parent-organization API keys in child organizations are attributed to and linked to the originating key. [PROD-906](https://linear.app/cycloid/issue/PROD-906/attribute-events-to-the-parent-org-api-key-when-it-acts-in-a-child)
* **User interface:** Navigation and organization-management icons load reliably without depending on intermittent external icon requests. [ENG-461](https://linear.app/cycloid/issue/ENG-461/some-cycloid-icons-are-not-displayed)

## 🐛 Fixes

* **Build logs:** Streams now require authentication and pipeline read access, returning 401 or 403 when access is missing. [PROD-900](https://linear.app/cycloid/issue/PROD-900/enforce-authentication-and-pipeline-permissions-on-the-build-log)
* **Authorization:** Scoped-resource list queries no longer interpolate rule values into SQL, preventing cross-organization access through crafted resource names. [PROD-903](https://linear.app/cycloid/issue/PROD-903/bind-the-allowed-canonicals-of-scoped-rules-as-sql-parameters-in-list)
* **Plugins:** HTTP 500 responses are recorded at error level so they are captured by standard alerting. [PROD-894](https://linear.app/cycloid/issue/PROD-894/server-errors-http-500-are-recorded-in-the-logs-as-info-instead-of)
* **Security:** API keys in plugin iframe paths are redacted from access logs, and anonymous panic responses no longer expose stack traces. [ENG-494](https://linear.app/cycloid/issue/ENG-494/http-middleware-leaks-secrets-api-key-in-access-logs-stack-trace-in)
* **StackForms:** Credential-backed values references no longer allow callers to choose an arbitrary destination host. [ENG-463](https://linear.app/cycloid/issue/ENG-463/values-ref-endpoints-resolve-any-org-credential-for-a-caller-chosen)
* **Authentication:** Revoking dedicated authentication in a parent organization now propagates to all descendants. [ENG-447](https://linear.app/cycloid/issue/ENG-447/fixorgs-propagate-revoked-dedicated-authentication-to-all-descendants)
