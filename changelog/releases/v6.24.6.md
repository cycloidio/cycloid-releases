# [v6.24.6] _2026-11-12_

*Security hardening for authentication and plugin integrations.*

## 🐛 Fixes

* **Authentication:** Unknown or empty SAML signing keys are rejected, preventing unauthenticated account takeover through forged social-login tokens. [ENG-534](https://linear.app/cycloid/issue/ENG-534/unauthenticated-account-takeover-the-saml-social-token-parser-accepts)
* **Plugins:** Iframe proxy paths can no longer escape the target plugin or send credentials to another host. [ENG-527](https://linear.app/cycloid/issue/ENG-527/plugin-iframe-proxy-follows-an-absolute-or-escaping-path-sending-the)
* **Plugins:** Interpolated iframe values are safely encoded so they cannot inject query parameters or override configuration-pinned values. [PROD-882](https://linear.app/cycloid/issue/PROD-882/plugin-iframe-widget-queries-interpolated-values-can-inject-query)
